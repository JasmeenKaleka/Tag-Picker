# Tag Picker

## What I changed

I improved the existing Tag Picker to make it more attractive, organized, and easier to use. I introduced a glassmorphic design with soft blue accents, cleaner typography, and a coding icon beside the title to give it a more distinctive identity. I also refined the dark theme with softer colors for a more comfortable viewing experience.

I reorganized the layout into four sections: Find Skills, Selected Skills, Suggested Skills, and Discover More Skills. Selected skills now appear directly below the search bar, making them easier to manage. I also grouped skills into categories so users can explore them without going through one long list.

I kept the existing search suggestions, keyboard navigation, custom skill entries, and the option to select or deselect skills with a click. I replaced the 100 character limit with a maximum of 10 skills. The design also adapts to different screen sizes, including mobile devices.

## Why I changed it

My main focus was to improve the user experience without changing what the component was originally built to do.

Keeping selected skills separate from the search field makes the interface cleaner and helps users see their choices immediately. The category system makes finding skills easier, while the suggestions help users discover related skills.

I chose a limit of 10 skills because counting characters did not seem practical. Skills have different name lengths, but that should not affect how many a user can select.

For the design, I wanted something that felt modern and professional while still reflecting a developer tool. The glass effects, blue colors, and subtle icons give the interface more personality without making it unnecessarily complicated.

## What I would improve with more time

I would add more keyboard shortcuts and improve the accessibility features, particularly for people using screen readers.

I would also consider allowing users to rearrange their selected skills based on priority and save their selections for future visits.

These additions could make the component more flexible while keeping the current experience simple and easy to use.
